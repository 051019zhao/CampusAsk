# 校园知识库内容指南

RAG 只能检索已审核的知识条目和用户当前会话的资料。知识质量取决于来源、适用范围和更新状态；不要把未经核实的校园政策写成确定事实。

## 每条知识建议包含

- **标题**：使用学生实际会问的问题或办理事项名称，例如“图书馆借阅规则”，避免“通知一”这类泛称。
- **分类**：使用稳定的业务分类，如教务、资助、图书馆。分类会参与索引。
- **关键词**：填写常见简称、正式名称和同义说法，逗号分隔；只填确实指向同一事项的词。关键词会参与索引，但不会自动变成事实。
- **正文**：先给可核实的结论，再说明适用校区、对象、条件、办理步骤和例外。一条记录尽量只覆盖一个政策或流程。
- **来源与时效**：在正文写明官方来源链接或文件名、发布日期、适用学期及核对日期。链接失效或政策更新时，重新审核正文。
- **无法确认的信息**：明确写“需向相关部门核实”，不要填猜测的电话、地点、金额或截止时间。

官网采集内容须经管理员审核后再发布。对于相互冲突的公告，先核对适用对象与日期，不要把两个版本拼成一个确定答案。

## 验证建议

建立一份人工标注的问题集，覆盖常见说法、简称、追问、无答案问题、跨校区与过期公告。逐条检查命中的来源、引用是否支持答案，以及模型在没有依据时是否明确说明。接入实际中文向量模型后，再据此调节召回阈值和关键词，不使用演示数据推断真实准确率。
